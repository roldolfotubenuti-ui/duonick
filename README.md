# DUONICK — Plataforma de Agendamento

> **PROGRAME. PUBLIQUE. EM TODAS AS REDES.**

Landing page de alta conversão, responsiva e com design editorial inspirada em pôster moderno, voltada para agendamento e publicação em massa de vídeos, fotos, Reels e Shorts em múltiplas redes sociais (Instagram, TikTok e YouTube).

---

## 🚀 Recursos da Página

- **Design Editorial Moderno**: Estética com títulos condensados em caixa alta, paleta de cores limpa (`#DCE6E7`, `#080A0A`, `#63FF18`) e faixa diagonal translúcida.
- **Biblioteca de Mídias Interativa**: Miniaturas reais de vídeos, fotos e Shorts com modal interativo de pré-visualização.
- **Calendário de Publicação Visual**: Navegação entre meses e destaques interativos em dias agendados com sumário das redes.
- **Controle de Redes Sociais**: Chaves seletoras (switches) ativas para Instagram, TikTok, YouTube, Shorts e Reels.
- **Seção de Planos com Precificação Dinâmica**:
  - **BÁSICO**: R$ 49,90/mês (1 conta conectada).
  - **PRO**: R$ 67,90/mês (2 contas conectadas · Mais Escolhido).
  - **PERSONALIZADO**: Seletor dinâmico com botões `−` e `+` navegando pelos patamares comerciais oficiais:
    - **Starter** (3 contas): R$ 99,90/mês *(Economizou R$ 49,80/mês)*
    - **Pro** (5 contas): R$ 159,90/mês *(Economizou R$ 89,60/mês)*
    - **Business** (10 contas): R$ 279,90/mês *(Economizou R$ 219,10/mês)*
- **Identidade Visual Oficial**: Logomarca oficial DUO no cabeçalho, rodapé e favicon.
- **Responsividade Total**: Layout adaptável para smartphones, tablets e desktops.

---

## 🛠️ Tecnologias

- **HTML5 & CSS3 Vanilla** (Variáveis CSS, Flexbox, Grid e KaTeX/Google Fonts)
- **JavaScript Moderno (ES6+)**
- **Node.js** (Servidor HTTP nativo com detecção automática de portas)

---

## 📦 Como Executar Localmente

1. Clone o repositório:
```bash
git clone https://github.com/roldolfotubenuti-ui/duonick.git
cd duonick
```

2. Inicie o servidor local:
```bash
npm run dev
# ou
node server.js
```

3. Acesse no navegador:
```
http://localhost:3080/
```
